## A) New deterministic checks

**None recommended.** The candidate technical ideas deduplicate against `docs/research/03-check-catalog.md`: title uniqueness (`seo.title.unique`), answer visibility and first-answer placement (`aeo.answer-first`, `aeo.visible-content-parity`), valid dates (`aeo.content.freshness-signal`), sitemap/link health (`site.sitemap.discovery`, `site.orphan-pages`, `crawl.sitemap.url-quality`), indexability (`crawl.*`), and source-backed claims (`entity.fact-support`, `geo.citations`).

Competitor sitemap diffs, live SERP position, and cross-engine citation counts require external datasets/accounts or repeated observations. They are not deterministic checks computable from a single site's HTML/headers/robots/sitemap/crawl graph, so do not encode them as site pass/fail checks. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [Vercel article](https://vercel.com/blog/how-were-adapting-seo-for-llms-and-ai-search).

## B) LLM-judge rubric refinements

No new standalone catalog check recommended; these are useful scoring anchors for existing checks:

- **Evidence-backed differentiation** (augment `entity.fact-support`): **0** = generic/unverifiable superlatives or copied claims; **2** = some specific examples but provenance, date, or method is missing; **4** = material differentiators are firsthand or linked to credible sources, scoped, dated where relevant, and accurately qualified. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [Vercel article](https://vercel.com/blog/how-were-adapting-seo-for-llms-and-ai-search)
- **SERP-intent coverage** (augment `geo.query-alignment`): **0** = page type/answer conflicts with observed query intent; **2** = intent broadly matches but misses a major format/topic expected by multiple top results; **4** = directly answers intent and includes relevant missing evidence/examples while retaining a defensible unique angle. Do not reward word-count parity. [blog-refresher](https://github.com/Illyism/seo-skills/blob/main/seo/blog-refresher/SKILL.md)
- **Comparison fairness** (candidate addition to `entity.fact-support`): **0** = unsupported competitor claims or one-sided strawman; **2** = sourced claims but no as-of date or material tradeoffs; **4** = each material claim has a source and date, and the page states where each option is stronger/weaker. Treat unsupported claim assertions as a defect, not a ranking trick. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md)

## C) Coding-agent fix playbooks and prompt patterns

- **Establish repo truth before editing.** Inspect framework, route/content conventions, metadata, canonical, sitemap, robots, and schema implementations; derive product facts from source code/live product pages and record file/URL provenance in a durable context file. Add pages through existing conventions. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md)
- **Persist repeat-run state in the repo.** The autopilot proposes `seo/context.md`, `seo/keyword-map.csv`, `seo/backlog.md`, `seo/log.md`, `seo/ai-prompts.md`, competitor sitemap snapshots, and dated reports. Re-read/update at each run; label unavailable data rather than guessing. This makes agent work auditable and resumable. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md)
- **Prioritize by observed opportunity and conversion.** Select an existing page ranking roughly positions 8–20 with real impressions and buyer intent; inspect top 3–10 live results, compare intent/sections/freshness/evidence, then ship one scoped page fix. Backlog by expected signups per work hour; do not treat page count or word count as an outcome. The Blitz skill's daily backlink quotas and day-14 ranking forecast are unsupported and should be omitted. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [blog-refresher](https://github.com/Illyism/seo-skills/blob/main/seo/blog-refresher/SKILL.md); [blitz-seo](https://github.com/Illyism/seo-skills/blob/main/seo/blitz-seo/SKILL.md)
- **Refresh safely.** Preserve URL, ranking sections, voice, and inbound-link anchors; present a gap-based plan (current-state audit → live SERP → competitor matrix → prioritized changes → approval → rewrite). Cite/date updated facts, add only supported differentiators, and output a publisher handoff (metadata, internal links, schema, images, redirect decision). [blog-refresher](https://github.com/Illyism/seo-skills/blob/main/seo/blog-refresher/SKILL.md)
- **Title rewrite prompt pattern:** “Treat the current SERP as the brief. Infer one primary query and intent from page + available SERP; draft 3–5 accurate titles; choose the clearest concise title matching intent. Preserve slug unless requested or demonstrably harmful. Change H1/meta only when mismatch is real. Return before/after plus rationale.” The skill suggests 40–55 chars as a heuristic, not a ranking threshold; do not force it. [seo-title-optimization](https://github.com/Illyism/seo-skills/blob/main/seo/seo-title-optimization/SKILL.md)
- **New-page acceptance checklist:** answer in opening two sentences; source every factual claim; use product-specific evidence; add title, description, canonical, sitemap entry, relevant schema, and at least three contextual internal links; ensure free tools work without signup when that is their value proposition. Place content/components according to the detected repo's route and content system, rather than prescribing one universal framework path. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [Vercel article](https://vercel.com/blog/how-were-adapting-seo-for-llms-and-ai-search)
- **Operational guardrails:** distinguish drafts from shipped changes; report what changed with source-linked measurements; do not invent rankings or conversions; do not publish outreach/social content or buy links automatically; require explicit approval before destructive redirect/removal of a page with traffic/backlinks. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [blog-refresher](https://github.com/Illyism/seo-skills/blob/main/seo/blog-refresher/SKILL.md)

## D) Product ideas

- **SERP reverse-engineering workspace — medium feasibility.** Given a target query, collect top 5–10 results, titles, visible result features, headings, page type, update dates, examples/data/tools; produce a comparison matrix and proposed gaps. Requires a SERP provider or compliant search collection plus robust page fetching. Do not equate competitor word count with quality or promise outranking. [blog-refresher](https://github.com/Illyism/seo-skills/blob/main/seo/blog-refresher/SKILL.md)
- **Buyer-journey query planner — high feasibility with human review.** Generate natural questions for unaware/problem/solution/product/most-aware stages from verified product context and customer call notes; map each to an existing URL or explicit content gap. Avoid asserting search volume unless connected to a source. [customer-journey](https://github.com/Illyism/seo-skills/blob/main/marketing/customer-journey/SKILL.md); [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md)
- **Programmatic page opportunity validator — medium feasibility.** Before generating location/integration/use-case/alternative pages, require distinct, verifiable facts per intended page, an existing product capability, demand evidence, and a crawl/internal-link plan; reject name-swap/doorway templates. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [Vercel article](https://vercel.com/blog/how-were-adapting-seo-for-llms-and-ai-search)
- **AI-answer observation log — medium/low feasibility.** Store a fixed, versioned prompt set with platform, timestamp, exact response, brand/competitor mentions, cited URLs, and sampling settings; compare only like-for-like runs and show sample size. This is an observational trend tool, not a universal visibility score or causal attribution. The repo catalog already advises preserving these dimensions. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md); [Vercel article](https://vercel.com/blog/how-were-adapting-seo-for-llms-and-ai-search); [catalog guidance](../03-check-catalog.md)
- **Commit-to-fact page maintenance — high feasibility.** Compare product/pricing/limit/integration changes in commits against sourced claims in tracked pages; emit candidate edits and cited diffs for review. Search result positions or ARR changes are not evidence that a content edit caused growth. [seo-autopilot](https://github.com/Illyism/seo-skills/blob/main/seo/seo-autopilot/SKILL.md)

## Review notes

- The `seo-skills` repo README advertises an SEO autopilot, title/blog workflows, backlink purchasing, and a 71-check hand checklist. The evaluated core skills are useful as process templates, but the checklist's overlap is substantial and this review found no catalog-worthy novel deterministic rule.
- Vercel's 2025 article explicitly says there is no reliable dashboard for AI visibility and that no single metric confirms usage. Treat traffic/referrers, visible citations, mentions, and index coverage as separate observations. Do not promote article claims about what models “reward” into deterministic rules.
- Excluded as unsupported growth claims: Railway ARR/model-selection claims; “#1 in 10 hours”; fixed backlink/day quotas and projected ranking dates; average AI referral engagement/conversion statistics; daily citation-velocity prescriptions; universal citation uplift assumptions.
